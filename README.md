# MasterPizza · Cardápio e carrinho

Projeto de front-end em HTML, CSS e JavaScript. O visitante percorre um cardápio de pizzas e bebidas, escolhe produtos e acompanha o valor do pedido no carrinho.

[**Abrir a demonstração**](https://jefersonschmitz.github.io/pizza-delivery-system/)

## Experimente

Adicione uma pizza e uma bebida ao carrinho. Abra o carrinho, confira o total e remova um dos itens para ver o valor ser recalculado. A opção **Fazer Pedido** abre o formulário de dados de entrega.

## Por dentro do código

- [index.html](index.html) organiza o cardápio, o carrinho e o formulário.
- [index.js](index.js) mantém os itens selecionados em memória e atualiza a lista e o total a cada alteração.
- [style.css](style.css) reúne os estilos da interface.

Para explorar localmente, baixe o repositório e abra `index.html` no navegador.
